# `#cybersécurité`

Sous-domaine de `#tech`.

Utiliser pour les contenus principalement consacrés à la protection des systèmes, réseaux, applications ou données contre les attaques informatiques, ainsi qu'à l'étude des vulnérabilités, intrusions et mécanismes de défense.

Cela comprend notamment :

- les vulnérabilités et techniques d'exploitation ;
- les attaques, intrusions, compromissions et fuites de données ;
- la sécurisation des applications, systèmes et réseaux ;
- l'authentification, le contrôle d'accès et la cryptographie lorsqu'ils sont abordés sous l'angle de la sécurité informatique ;
- les audits de sécurité, tests d'intrusion et réponses à incident ;
- l'actualité portant principalement sur une cyberattaque ou une vulnérabilité importante.

## Conventions

- `#cybersécurité` a `#tech` pour parent.
- Ne pas utiliser `#sécurité` comme synonyme : le tag canonique pour la sécurité informatique est `#cybersécurité`.
- Ajouter les tags techniques, thématiques ou éditoriaux qui décrivent réellement le contenu.
- Ne pas attribuer `#cybersécurité` simplement parce qu'une technologie liée à la sécurité est mentionnée ou utilisée.
- Le sujet du contenu doit porter réellement sur la sécurité informatique.

### Exemples

- Tutoriel sur l'injection SQL : `#tech #dev #cybersécurité #bdd #tutoriel`
- Actualité sur le piratage d'un site important : `#tech #cybersécurité #actualité`
- Analyse d'une fuite de données provoquée par une mauvaise authentification : `#tech #cybersécurité #analyse`
- Sécurisation d'une API : `#tech #dev #cybersécurité #api`

## Cas ne justifiant pas automatiquement `#cybersécurité`

- utilisation du TPM pour contrôler les licences ou lutter contre le piratage logiciel ;
- discussion sur les DRM et les restrictions imposées par un éditeur ;
- annonce d'un produit utilisant le chiffrement sans analyse de sa sécurité ;
- contenu sur la collecte de données relevant principalement de `#vie-privée`.

Ainsi, une actualité sur Microsoft utilisant le TPM pour renforcer l'activation de Windows peut recevoir `#tech #actualité`, sans `#cybersécurité`, si la discussion porte surtout sur les licences, les DRM et la stratégie de l'entreprise.
