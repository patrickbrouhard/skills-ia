# `#tech`

Utiliser pour les contenus principalement consacrés aux technologies numériques, à l'informatique ou aux domaines techniques associés.

Sous-domaines courants :

- `#dev` : développement logiciel, programmation, langages → `dev.md`
- `#ia` : intelligence artificielle, machine learning, modèles génératifs → `ia.md`
- `#devops` : déploiement, CI/CD, conteneurisation, infrastructure automatisée → `devops.md`
- `#cybersécurité` : sécurité informatique, vulnérabilités, attaques et défense → `cybersécurité.md`

Pour un sujet technique évident qui ne nécessite pas de convention particulière, utiliser directement le tag pertinent sans consulter de référence supplémentaire.
