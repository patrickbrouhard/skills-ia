# `#business`

Utiliser pour les contenus principalement consacrés à la création, à la gestion, à la stratégie, au fonctionnement ou au développement d'une entreprise.

Cela comprend notamment :

* l'entrepreneuriat ;
* les modèles économiques ;
* la stratégie commerciale ;
* le marketing ;
* la vente ;
* le management ;
* les startups ;
* la productivité des organisations ;
* l'analyse d'entreprises.

## Conventions

* Ajouter un tag plus précis lorsqu'une fonction, une pratique ou un type d'entreprise constitue un sujet important du contenu.
* Ne pas attribuer `#business` simplement parce qu'une entreprise est mentionnée.
* Lorsqu'un contenu analyse principalement une entreprise comme organisation, activité commerciale ou acteur stratégique, utiliser `#business`.
* Lorsqu'un contenu croise d'autres domaines, conserver également les branches pertinentes, par exemple `#économie`, `#finance`, `#tech`, `#ia` ou `#politique`.

## Tags spécifiques courants

* `#entrepreneuriat`
* `#startup`
* `#marketing`
* `#vente`
* `#management`
* `#stratégie`
* `#productivité`

Ces tags peuvent être utilisés avec `#business` lorsqu'ils décrivent réellement un sujet important du contenu.

### Exemples

* Comment lancer une startup : `#business #entrepreneuriat #startup`
* Stratégie marketing d'une entreprise : `#business #marketing #stratégie`
* Techniques de vente B2B : `#business #vente`
* Organisation et management d'une équipe : `#business #management`
* Automatisation d'une entreprise grâce à l'IA : `#business #ia #automatisation`

## Business, finance et investissement

`#finance` et `#investissement` ne sont pas nécessairement des sous-domaines de `#business`.

Les utiliser comme branches complémentaires lorsque le contenu porte réellement sur ces sujets.

### Exemples

* Analyse financière d'une entreprise technologique : `#business #finance #tech`
* Stratégie de financement d'une startup : `#business #startup #finance`
* Analyse d'une entreprise comme opportunité d'investissement : `#business #finance #investissement`

Ne pas attribuer automatiquement `#business` à tout contenu financier ou consacré à l'investissement.

## Distinction entre `#business` et `#économie`

Utiliser `#business` lorsque le sujet principal concerne les entreprises, les entrepreneurs, les organisations ou leur fonctionnement.

Utiliser `#économie` lorsque le sujet porte principalement sur des phénomènes économiques plus larges, par exemple :

* l'inflation ;
* l'emploi ;
* les taux d'intérêt ;
* les cycles économiques ;
* les marchés à l'échelle sectorielle ou macroéconomique ;
* les politiques économiques ;
* les systèmes économiques.

Les deux tags peuvent être utilisés lorsque le contenu analyse explicitement le lien entre ces deux niveaux.

### Exemples

* Comment augmenter les ventes d'une entreprise : `#business #vente`
* Analyse de l'inflation : `#économie`
* Effets des taux d'intérêt sur les entreprises : `#économie #business #finance`
* Conséquences d'une récession sur les startups : `#économie #business #startup`

## Cas ne justifiant pas automatiquement `#business`

* actualité mentionnant une entreprise sans analyser son activité ou sa stratégie ;
* présentation purement technique d'un produit ou d'un logiciel développé par une entreprise ;
* analyse macroéconomique citant plusieurs sociétés à titre d'exemple ;
* contenu financier consacré uniquement aux marchés ou aux actifs sans angle entrepreneurial ou organisationnel ;
* contenu sur la carrière ou la productivité personnelle sans lien réel avec le fonctionnement d'une organisation.
