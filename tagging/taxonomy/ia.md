# `#ia`

Sous-domaine de `#tech`.
Utiliser pour les contenus principalement consacrés à l’intelligence artificielle, à l’apprentissage automatique, aux modèles génératifs, aux modèles de langage ou aux usages de l’IA.

## Conventions

- Ajouter des tags complémentaires pour préciser la technologie, le type de modèle ou le domaine d’application lorsqu’ils constituent un sujet important du contenu.
- `#llm`, `#machine-learning` et `#deep-learning` ont `#ia` pour parent.
- Utiliser `#agent` pour les contenus consacrés aux agents IA ou aux systèmes agentiques, pas simplement pour tout assistant fondé sur un LLM.
- Utiliser `#prompting` lorsque la conception ou l’optimisation de prompts constitue un sujet réel du contenu.
- Les tags comme `#image`, `#video` et `#audio` décrivent la modalité traitée ; ils ne remplacent pas `#ia`.
- Lorsqu’un contenu applique l’IA à un autre domaine, conserver également la branche correspondante : `#dev`, `#business`, `#science`, etc.

### Exemples

- Présentation générale de l’intelligence artificielle : `#tech #ia`
- Utilisation de l’IA pour programmer : `#tech #ia #dev`
- Assistant de programmation fondé sur un LLM : `#tech #ia #llm #dev`
- Génération d’images : `#tech #ia #image`
- Génération de vidéos : `#tech #ia #video`
- Génération ou traitement de musique : `#tech #ia #audio #musique`
- Automatisation d’une entreprise avec l’IA : `#tech #ia #business #automatisation`
- Recherche scientifique utilisant le machine learning : `#tech #ia #machine-learning #science`
