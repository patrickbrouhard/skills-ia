# `#dev`

Sous-domaine de `#tech`.
Utiliser pour les contenus principalement consacrés au développement logiciel, à la programmation, à l’architecture logicielle, aux outils de développement, aux frameworks, aux bibliothèques, aux API, aux tests ou au débogage.

## Conventions

- Un langage de programmation qui constitue un sujet important du contenu reçoit son propre tag, par exemple `#rust`, `#python`, `#go`.
- Les tags de langages ont `#dev` pour parent.
- Ne pas attribuer le tag d'un langage simplement parce qu'un extrait de code apparaît.
- Un framework ou une bibliothèque reçoit son propre tag seulement s'il constitue un sujet central ou suffisamment important pour retrouver le contenu.
- Utiliser des tags fonctionnels comme `#frontend`, `#backend`, `#web` ou `#mobile` lorsqu'ils décrivent réellement le domaine traité, et non simplement la technologie employée.

### Exemples

- Tutoriel général sur la programmation : `#tech #dev`
- Tutoriel Python : `#tech #dev #python`
- Développement d'une API en Go : `#tech #dev #go #api`
- Tests automatisés en Java : `#tech #dev #java #test`

## Tags spécifiques courants

- `#web`
- `#frontend`
- `#backend`
- `#mobile`
- `#api`
- `#test`

## Conventions de nommage

- C++ → `#cpp`
- C# → `#csharp`
- Base de données → `#bdd`
